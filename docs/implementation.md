# Inside the Runtime

## Audit
The supplied workspace is empty. There is no framework, repository history, CV, contact information, or existing functionality to preserve. The user's attached brief is the content source. Contact URLs must be supplied by the owner, never guessed.

## Design
An editorial systems portfolio for Srijit Gyawali. Ink #060708, paper #F2F1ED, signal #B7FF4A. Oversized condensed display type, a neutral body face, monospace metadata. Asymmetric layouts with generous quiet space. A procedural structure built from points and wire segments is the continuous visual thread.

## Implementation sequence
1. React + TypeScript + Vite foundation; self-hosted fonts; accessible semantic content and responsive styling.
2. One persistent lazy-loaded Three.js canvas. Reused particles morph across identity, network, sensor/ledger, matching engine, verification gate, agent topology, architecture, and collapse states.
3. Isolated StringTune scroll service feeds a mutable runtime store; Anime.js owns DOM typography choreography. No frame-driven React state.
4. Project chapters and readable detail dialogs, quick project index, capability selector, live illustrative architecture flow, contact data configuration.
5. Reduced motion, motion pause, adaptive resolution, WebGL fallback, touch layouts, visibility pause, disposal, keyboard/focus restoration.
6. Verify geometry/scroll math, lint, typecheck, build, browser navigation, detail dialogs, mobile layouts, reduced motion and renderer failure.

## Boundaries
- `src/animation`: mutable runtime state and verified StringTune adapter.
- `src/webgl`: renderer lifecycle, procedural targets, camera, particles, edges and packets.
- `src/components`: semantic sections, project details/index, navigation and cursor.
- `src/data`: owner-provided content, projects, technologies and optional URLs.
- `src/styles`: tokens, composition, responsive layouts and accessibility.

The existing brief explicitly authorizes creative decisions and immediate implementation. No additional design approval is needed. Native mobile scroll and all content must remain usable without WebGL. No fictitious contact addresses, performance metrics, project dates or links.
